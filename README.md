# Birthday story website

Update the `content` object at the top of `script.js`. It contains every name, message, caption, and media path.

- Put photos in `assets/images/`, then set a memory `image` to e.g. `assets/images/trip.jpg`.
- Put all video clips in `assets/videos/`, then set the relevant `video` path, e.g. `assets/videos/mom.mp4`.

For a local server, run `python -m http.server 8080` here and open `http://localhost:8080`.

For a fast mobile experience, use compressed JPG/WebP photos and H.264 MP4 videos.
